## What you need

- **WebGPU.** In a browser, or [headless](./headless.mdx): in Node with Dawn's bindings, and in Deno.
- **The library.** `npm install skia-wasm`. In the package, `dist/lib` holds three files to serve together: `index.js`, `skia-wasm.js` and `skia-wasm.wasm`.
- **A canvas.** The examples of this site use one of 512 by 512.

```html
<canvas width="512" height="512"></canvas>
<script type="module" src="main.js"></script>
```

## A first frame

Five things happen here:

1. **The device is yours.** Skia draws with the `GPUDevice` of the page. That is why it can wrap your textures, and why your own WebGPU code can run next to it.
2. **`Skia.init()` gives you `sk`.** It loads the wasm module and creates Skia's context on the device. Everything else comes from `sk`.
3. **A surface is where drawing ends up.** `sk.surface()` takes the canvas and configures it for the device.
4. **A paint says how to draw.** A color here; it also holds strokes, shaders, blend modes and filters.
5. **A frame is `getCanvas()`, draw, `flush()`.** Nothing reaches the GPU before the flush.

## Animating

Draw one frame per animation frame. The canvas of a new frame starts from scratch: no transform and no clip carry over from the previous one.

```ts
const frame = (time: number) => {
  const canvas = surface.getCanvas();
  canvas.clear("white");
  canvas.rotate(time / 1000, 256, 256);
  canvas.drawRoundedRect(96, 156, 320, 200, 32, paint);
  surface.flush();
  requestAnimationFrame(frame);
};
requestAnimationFrame(frame);
```

## One device, many surfaces

`sk` is not tied to a canvas. Call `Skia.init()` once per device, then make a surface for everything you draw to:

```ts
const sk = await Skia.init({ device });

const main = sk.surface(document.querySelector("#main")!);
const minimap = sk.surface(document.querySelector("#minimap")!);
const target = sk.surface(texture); // a GPUTexture of yours
const offscreen = sk.offscreenSurface(256, 256); // Skia owns the texture
```

A canvas of the page, an `OffscreenCanvas` and a `GPUTexture` all work. What `sk` makes is shared by all of them: one paint, one image or one runtime effect can be drawn to every surface, and a snapshot of an offscreen surface is an image like any other.

Frames are per surface. Several can be open at once, and they can be flushed in any order.

A second `Skia.init()` is a second copy of the wasm module, with objects of its own. It is what another device needs, not another canvas.

## Where the module is loaded from

The library loads `skia-wasm.js` from the folder of the file it is in, and `skia-wasm.js` loads `skia-wasm.wasm` from its own. Served as they are, the three files of `dist/lib` find each other.

A bundler moves the library into a bundle of yours. Either copy `skia-wasm.js` and `skia-wasm.wasm` (from `node_modules/skia-wasm/dist/lib`) next to that bundle, or say where they are:

```ts
const sk = await Skia.init({
  device,
  module: new URL("/skia/skia-wasm.js", location.href).href,
});
const surface = sk.surface(canvas);
```
