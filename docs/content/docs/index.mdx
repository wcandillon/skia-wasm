Two short guides, then examples. Each example runs live above its code. It is a complete module that expects a page with a 512 by 512 `<canvas>`, in a browser with WebGPU. Without a page, see [Headless](./headless.mdx).

The API is a canvas, paints and paths, in the style of CanvasKit, with plain numbers for geometry and CSS strings for colors.
